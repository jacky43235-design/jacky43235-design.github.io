## GitHub 更新方式
1. 解壓縮 ZIP，進入 Repository 根目錄。
2. 用 GitHub `Add file` → `Upload files` 上傳 `index.html`、`stories`、`assets` 的內容，保持相同路徑；若網頁版無法保留資料夾，可使用 GitHub 網頁建立路徑為 `stories/rose.html` 等檔案，或透過 GitHub Desktop 上傳整個資料夾。
3. Commit changes 到 `main`，等待 GitHub Pages 部署。
4. 重新整理 https://jacky43235-design.github.io/ 。
